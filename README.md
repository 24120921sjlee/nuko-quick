# Nuko Quick!

A cute browser reaction-time game with an early-2000s web layout.

## Play locally

Open `index.html` in a browser, press **Start**, wait for Nuko's image to change, and click as quickly as possible.

## Features

- Random wait between 2 and 5 seconds
- Reaction time shown in seconds and milliseconds
- False-start detection
- Best score saved in the browser
- Keyboard and touch support
